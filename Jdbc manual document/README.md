### 📑 Topics Covered in Manual

1. **System Architecture:** Clean separation of Swing GUI, Service layer, Database DAO layer, and PDF generator.
2. **Database Schema & E-R Model:** MySQL relational tables, foreign keys, cascading constraints, and audit logs.
3. **JDBC Implementation:** Connection pooling, `PreparedStatement` parameterization, transactional commit/rollback, and SQL exception handling.
4. **Security & Authentication:** Salted BCrypt password hashing and role-based permissions (Admin, Faculty, Student).
5. **R2024 Evaluation Engine:** Course evaluation formulas, continuous internal assessments, ESE grading, SGPA calculation, and attendance rules.
6. **PDF Generation:** Dynamic institutional marksheets generated via Apache PDFBox with college crest and tabular layout.
